# JS→TS 道場

スマホで書いて、実行して、身につける。JavaScript の基礎から TypeScript まで進む 23 レッスンの学習アプリです。

## 内容

- **Stage 1 JS 基礎**：変数、データ型、比較、条件分岐、ループ、関数、配列、オブジェクト
- **Stage 2 JS 実践**：配列メソッド、分割代入とスプレッド、`?.` / `??`、クラス、async / await、エラー処理
- **Stage 3 TypeScript**：型注釈、関数の型、interface / type、ユニオン型、ジェネリクス、ユーティリティ型、JS→TS 書き換え

## 特徴

- コード例を書き換えてその場で実行（Web Worker で実行、5秒で自動停止）
- 練習問題は出力と書き方を自動判定
- TypeScript は本物のコンパイラ（strict）で型チェックしてから実行。型エラーに日本語の説明つき
- スマホ用の記号キーバー
- 進み具合はブラウザ（localStorage）に保存

## 使い方

`index.html` 1ファイルだけで動きます。ブラウザで開くか、GitHub Pages で公開してください。

GitHub Pages: リポジトリの **Settings → Pages → Branch: `main` / `/ (root)`** を選んで保存すると、数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。
